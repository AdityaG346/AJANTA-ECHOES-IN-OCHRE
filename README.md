# Ajanta: Echoes in Ochre — Workspace Root

This workspace contains the complete build for **Ajanta: Echoes in Ochre** located in the [`ajanta-echoes-in-ochre/`](./ajanta-echoes-in-ochre/) directory.

### Quick Start
To run the exhibition locally:
```bash
# Start HTTP server in project folder
cd ajanta-echoes-in-ochre
python -m http.server 5500
```
Then visit: `http://localhost:5500`
